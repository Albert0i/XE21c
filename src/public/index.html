YRunner API

Oracle SQL Runner

This API provides endpoints to run SQL commands and RESTful operations.

Examples (Employee Table)

  • Get all employees:
    GET /api/v1/yr/employee
  • Get one employee by ID:
    GET /api/v1/yr/employee/101?_keyname=id
  • Create a new employee:
    POST /api/v1/yr/employee
Content-Type: application/json

{
  "id": 102,
  "name": "Alice",
  "department": "HR"
}
  • Update an employee:
    PATCH /api/v1/yr/employee/102?_keyname=id
Content-Type: application/json

{
  "department": "Finance"
}
  • Delete an employee:
    DELETE /api/v1/yr/employee/102?_keyname=id
